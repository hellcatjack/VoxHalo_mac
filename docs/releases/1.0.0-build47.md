# LingoCove 1.0.0 · build 47 · 同声传译

中文 | English below

- **字幕更易阅读。** 分句和标点在连续两次识别中一致后，可以在句号前显示译文。阅读优先每次显示一张短字幕，每屏至少 2.4 秒，文字越多停留越久。完整译文按顺序分屏，朗读独立进行。
- **恢复部分因专名被拒绝的中译英句子。** 严格重试优先使用词表译名。找不到可靠译名时，根据可确认的原文专名给出拉丁字母音译。整句通过英文校验后才上字幕和进入朗读。
- **本机识别更新。** 使用 `mlx-qwen3-asr` 0.4.4 流式接口，搭配 Qwen3-ASR 0.6B 8-bit、HY-MT1.5 1.8B Q8_0 和 Kokoro。

同源音频的中英、英中回放均显示了全部定稿。每个方向均有带逗号的测试句在说完前上屏。原先因专名失败的句子在一次严格重试后完整显示并完成原生朗读。

在 Assets 下载 **LingoCove-1.0.0-macOS-arm64.dmg**，将 App 拖入「应用程序」。也可使用 ZIP。需要 Apple Silicon、macOS 14.2 或更高版本及至少 16 GB 内存。完成首次模型安装后，传译可在本机离线运行。升级前请退出旧 App，已有模型可继续使用。

公开安装包使用 ad-hoc 签名。下载后可用 `SHA256SUMS.txt` 校验文件。参见[中文安装指南](https://github.com/hellcatjack/VoxHalo_mac/blob/lingocove-v1.0.0-build47/docs/zh-CN/QUICKSTART.md)。

- **Steadier captions.** Reading first can show an early translation after the clause and its punctuation agree across two recognition updates. Each short screen stays visible for at least 2.4 seconds, with longer holds for denser text. Completed translations continue across screens in order. Speech runs independently.
- **Recover Chinese-to-English sentences rejected over proper names.** The strict retry favors glossary spellings and uses a Latin-script spelling when the source name can be identified. A passing translation is published in full to captions and speech.
- **Local ASR update.** This build uses the `mlx-qwen3-asr` 0.4.4 streaming API with Qwen3-ASR 0.6B 8-bit, alongside HY-MT1.5 1.8B Q8_0 and Kokoro.

The Chinese-to-English and English-to-Chinese replays showed all finalized translations. Each direction displayed a test clause before the spoken sentence ended. The previously rejected proper-name example passed one strict retry, displayed in full and finished native playback.

Download **LingoCove-1.0.0-macOS-arm64.dmg** under Assets and drag the App into Applications, or use the ZIP. Requires Apple Silicon, macOS 14.2 or later, and at least 16 GB RAM. Interpretation runs offline after model setup. Quit the previous App before upgrading. Existing model files can be reused.

The public package is ad-hoc signed. Verify downloads with `SHA256SUMS.txt`. See the [installation guide](https://github.com/hellcatjack/VoxHalo_mac/blob/lingocove-v1.0.0-build47/docs/en/QUICKSTART.md).
