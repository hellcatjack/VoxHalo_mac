# LingoCove 1.0.0 · build 44 · 同声传译

中文 | English below

本次将已验证的 build 44 发布为独立安装包，对外版本继续为 **1.0.0**。

- 阅读优先字幕独立于语音固化、合成与播放，在完整译文就绪后按原文顺序显示；仍可切换为跟随朗读。
- 优化快速中文→英文的字幕吞吐：英文采用独立的 288 词/分钟预算，每屏至少 3.5 秒，完整 36 词屏约 7.7 秒。固定字号，保留完整词、未读尾页、相同译文的阅读进度和改字号后的重排。
- 英文→中文的既有字幕计时及 TTS 保持不变。继续使用本机验证的 **Qwen3-ASR 0.6B MLX INT8、HY-MT1.5 1.8B Q8_0、Kokoro**。
- 保留八种界面及互译语言：中文、英文、日语、法语、西班牙语、意大利语、葡萄牙语、印地语；模型管理、系统音频／输入设备选择、字幕样式及全局快捷键继续可用。

**安装：**下载 DMG，打开后将 `LingoCove.app` 拖入“应用程序”；也提供同名 ZIP。需要 Apple Silicon、macOS 14.2+、至少 16 GB 内存。首次运行通过图形界面下载并校验模型及语音组件，完成后可完全本地离线传译；播放 YouTube 等在线内容本身仍需要网络。

**升级：**先退出旧 App，再替换“应用程序”中的 `LingoCove.app`。保留现有模型与设置，Release 运行环境和模型继续位于用户“应用程序支持”目录。

**验证范围：**已完成的 build 44 十分钟现场测试及真实队列回放覆盖字幕时长和已译文本守恒，详见[验证报告](https://github.com/hellcatjack/VoxHalo_mac/blob/main/VoxBridge/docs/MACOS-FAST-ZH2EN-CAPTIONS-VERIFICATION.md)。记录中仍有一条模型未按目标语言输出的失译，尚未修复。数字是译文发布代理到字幕首显的观测，不是端到端翻译延迟，不构成全部原文零遗漏或所有语言同等效果的承诺。

**本次发布检查：**本地完整回归 1492 项通过、33 项跳过，发布专项 95 项通过。独立运行环境通过搬移、本机 Metal、72 个原生库兼容性检查及关闭网络的模型／语音健康检测；首次启动安装界面、DMG 和 ZIP 完整性检查通过。

**签名与校验：**公开安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。可用 `SHA256SUMS.txt` 校验 DMG／ZIP；首次下载及权限授予遵循 macOS 的正常安全流程。

---

This standalone release includes the verified **build 44**, retaining public App version **1.0.0**.

- Reading first displays completed translations in source order independently of speech confirmation, synthesis and playback. Follow speech remains available.
- Improve captions for fast Chinese→English content with an independent 288-word/minute English budget, a 3.5-second minimum and about 7.7 seconds for a full 36-word screen. Preserve fixed font size, complete words, unread tails and progress across identical translations and manual font reflow.
- Keep English→Chinese timing and TTS unchanged. Retain the verified **Qwen3-ASR 0.6B MLX INT8, HY-MT1.5 1.8B Q8_0 and Kokoro** settings.
- Retain all eight interface/translation languages: Chinese, English, Japanese, French, Spanish, Italian, Portuguese and Hindi, plus model management, audio-device selection, subtitle styling and global shortcuts.

**Install:** open the DMG and drag `LingoCove.app` into Applications, or use the matching ZIP. Requires Apple Silicon, macOS 14.2+ and at least 16 GB RAM. The graphical installer downloads and verifies models/audio components on first use; interpretation then runs fully locally and offline. Online sources such as YouTube still need their own network connection.

**Upgrade:** quit the previous App before replacing it in Applications. Retain existing models/settings in the user's Application Support directory.

**Validation limits:** the existing build 44 long test and real-queue replay cover timing and conservation of successfully translated text. See the [verification report](https://github.com/hellcatjack/VoxHalo_mac/blob/main/VoxBridge/docs/MACOS-FAST-ZH2EN-CAPTIONS-VERIFICATION.md). One target-language model failure remains unresolved. Reported waits start at the published-translation proxy, not audio input; they do not guarantee zero source omissions or equal results in all languages.

**Release checks:** local full regression: 1492 passed, 33 skipped; release contracts: 95 passed. The standalone runtime passed relocation, local Metal, compatibility checks for 72 native libraries and offline model/speech health checks. The first-launch installer UI and DMG/ZIP integrity checks passed.

**Signing/checksums:** public packages are ad-hoc signed and are not Apple Developer ID notarized. Verify the DMG/ZIP against `SHA256SUMS.txt`; use normal macOS download and privacy-permission procedures.
