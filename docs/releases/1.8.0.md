## 简体中文

这是首个可独立下载的桌面发行版：下载 DMG，把 App 拖入“应用程序”，首次打开后在界面中安装模型。无需终端、Xcode、Homebrew、单独安装 Python 或云端 API 密钥。

- App 内模型安装：进度显示、取消、重试、断点续传及 SHA-256 校验。
- 独立运行环境，数据保存在用户“应用程序支持”目录；不依赖开发目录。
- 延续已验证的 Qwen3-ASR 0.6B INT8、HY-MT1.5-1.8B Q8_0 和 Kokoro 设置。
- 中文、英文、日语、法语、西班牙语、意大利语、葡萄牙语、印地语，支持 56 个方向和八语言界面。
- 原生音频采集、输出设备选择、同步字幕、局域网收听；关闭网页不影响同传。
- 首次下载需网络，安装后识别、翻译、朗读与字幕完全在本机运行，可离线使用。

**下载：**选择 `VoxHalo-1.8.0-macOS-arm64.dmg`（推荐），或同名 ZIP。`Source code` 不是桌面安装包。

**配置：**Apple Silicon，macOS 14.2+；安装器要求至少 16 GB 内存，预留 20 GB 空间。完整系统已在 M4 / 24 GB / macOS 26 上验证；其他机型的持续实时性能仍需验证。首次约下载 4.61 GB 模型及语音组件。

**首次打开：**本版为 ad-hoc 签名，尚无 Apple Developer ID 公证。macOS 可能要求在“隐私与安全性”中为此 App 选择“仍要打开”，无需关闭全局安全保护。

**模型许可：**HY-MT 遵循 Tencent HY Community License，许可地域不含欧盟、英国和韩国；安装前请在 App 中阅读完整条款并确认适用。软件公开免费不改变第三方模型许可。

## English

The first independently downloadable desktop release. Open the DMG, drag the App to Applications, and install the models through its first-run interface. No Terminal, Xcode, Homebrew, separate Python or cloud API key is required.

- Graphical model setup with progress, cancellation, retry, resumable downloads and SHA-256 verification.
- Portable runtime and per-user Application Support storage, independent of a developer checkout.
- Preserves the verified Qwen3-ASR 0.6B INT8, HY-MT1.5-1.8B Q8_0 and Kokoro configuration.
- Chinese, English, Japanese, French, Spanish, Italian, Portuguese and Hindi: 56 directions and eight interface languages.
- Native sound capture and device selection, synchronized subtitles and LAN listening; browser monitoring is optional.
- Internet is required for initial downloads. Installed recognition, translation, speech and subtitles run locally and work offline.

**Download:** choose `VoxHalo-1.8.0-macOS-arm64.dmg` (recommended), or the ZIP. GitHub's `Source code` archives are not desktop installers.

**Mac:** Apple Silicon, macOS 14.2+; the installer requires at least 16 GB memory and 20 GB free disk space. The full system is validated on M4 / 24 GB / macOS 26; sustained real-time performance on other configurations needs testing. Initial model/component downloads total approximately 4.61 GB.

**First open:** this release is ad-hoc signed and has not been notarized with an Apple Developer ID. macOS may require the per-App “Open Anyway” action in Privacy & Security. Do not disable global security protections.

**Model terms:** HY-MT has a separate Tencent HY Community License, whose territory excludes the EU, UK and South Korea. Review the full terms in the App and confirm eligibility before installing. Free public software availability does not change model licenses.
