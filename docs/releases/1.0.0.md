# LingoCove 1.0.0 · 同声传译

中文 | English below

VoxHalo／同声传译正式更名为 **LingoCove**。安装后的应用为 **LingoCove.app**，Finder、Dock 和八种界面语言均使用相同的英文名称。

- 沿用原应用标识、音频／字幕／界面设置和模型保存位置，无需因改名重新下载模型。
- 模型管理可查看 18 个模型及配套文件的大小、状态、保存路径、下载来源和校验值；支持误删恢复、损坏修复、进度显示、暂停和续传。
- 字幕设置支持放映时的全局快捷键：显示／隐藏、上下移动、移至顶部或底部，并允许修改末尾按键。
- 继续使用本机验证过的 Qwen3-ASR 0.6B MLX INT8、HY-MT1.5 1.8B Q8_0 和 Kokoro 设置；字幕控制独立于实际朗读。

**升级：**先退出旧 App，将 LingoCove.app 放入“应用程序”。确认新版正常后，把旧的同声传译.app 和旧快捷方式移到废纸篓。模型仍保存在原位置；发行版继续使用 `~/Library/Application Support/VoxHalo/`。

**安装包：**`LingoCove-1.0.0-macOS-arm64.dmg` 或同名 ZIP。面向 Apple Silicon、macOS 14.2+、至少 16 GB 内存。使用 ad-hoc 签名，未经过 Apple Developer ID 公证；模型与依赖遵循各自许可证。

VoxHalo / Simultaneous Interpretation is now **LingoCove**. The installed application is **LingoCove.app**, with the same English name in Finder, the Dock and all eight interface languages.

- Keep the existing bundle identity, audio/subtitle/interface preferences and model locations. Renaming does not require model downloads.
- Inspect 18 model/supporting files, their sizes, states, locations, download sources and checksums. Recover missing files, repair damaged files, monitor progress, pause and resume.
- Control subtitles during presentations with global show/hide, move up/down and top/bottom shortcuts; customize their final keys in subtitle settings.
- Preserve the verified local Qwen3-ASR 0.6B MLX INT8, HY-MT1.5 1.8B Q8_0 and Kokoro settings. Subtitle controls remain independent of spoken output.

**Upgrade:** quit the previous App, then copy LingoCove.app into Applications. After verifying it, move the old 同声传译.app and shortcut to Trash. Models remain in place; release installations retain `~/Library/Application Support/VoxHalo/`.

**Packages:** `LingoCove-1.0.0-macOS-arm64.dmg` or the matching ZIP. Requires Apple Silicon, macOS 14.2+ and at least 16 GB memory. Ad-hoc signed, without Apple Developer ID notarization; models and dependencies retain their respective licenses.
