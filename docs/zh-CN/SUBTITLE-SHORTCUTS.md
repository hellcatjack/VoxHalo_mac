# 放映时控制字幕

[English](../en/SUBTITLE-SHORTCUTS.md)

此功能已包含在 **LingoCove 1.0.0** 及后续版本中。

开始传译后，即使 PowerPoint 正在全屏放映，也可以直接操作字幕，无需切回 LingoCove。快捷键仅改变桌面字幕的显示与位置；语音识别、翻译、朗读和网页监控继续运行。

| 默认快捷键 | 操作 |
|---|---|
| Control + Shift + Command + S | 显示／隐藏字幕 |
| Control + Shift + Command + B | 显示／隐藏字幕矩形背景 |
| Control + Shift + Command + ↑ | 字幕向上移动 |
| Control + Shift + Command + ↓ | 字幕向下移动 |
| Control + Shift + Command + 9 | 字幕移至当前显示器顶部 |
| Control + Shift + Command + 0 | 字幕移至当前显示器底部，可覆盖 Dock |

方向键每次移动 **8 个屏幕逻辑点**。按住约 0.3 秒后连续移动，松开即停；到屏幕边缘自动停止。位置会自动保存。顶部／底部操作只调整垂直位置，保留水平位置和选择的字幕显示器。

隐藏期间，字幕仍跟随当前朗读；恢复显示时不会补放旧句子。本机不播放时，长译文的分页也会继续计时，移动字幕不会把它重置到第一页。没有当前译文时，显示快捷键不会生成预览文字或启动传译。

在 **字幕设置…** 中勾选 **启用矩形背景**，可以为当前字幕加上实心矩形底色。背景默认关闭，与文字阴影共用 **阴影与背景颜色** 和 **阴影与背景浓度**；关闭阴影后也能独立使用背景。背景按当前文字的实际边界自动调整宽高，只保留少量内边距；每一行文字都有独立的贴合背景框，自动换行也适用，行间保持透明；空行及无字幕时不显示背景。字幕宽度设置仍用于控制换行，不会固定背景宽度。切换背景不会改变文字、分页进度或朗读。设置自动保存；若旧版已将 B 分配给其他操作，新操作会使用空闲按键，以设置页为准。

## 修改快捷键

打开 **字幕设置…**，向下滚动到 **传译时启用全局快捷键**。可以关闭整组快捷键、修改每个操作的末尾按键，或点击 **恢复默认快捷键**。Control、Shift、Command 三个修饰键保持固定，以避免注册裸方向键、空格或 Esc。已分配给其他字幕操作的按键不可重复选择。

表格按美式键盘标注；其他布局请以设置页显示的键位为准。键位保留物理位置，显示名称随当前键盘布局更新，例如 AZERTY 与 QWERTY 的 A/Q 会正确区分。

快捷键只在传译运行和停止后的音频收尾阶段注册；停止完成、关闭快捷键或退出 App 后释放。App 检查系统预留键位并独占注册热键；无法注册时，控制面板和字幕设置会显示提示，其余可用快捷键继续工作。可更换末尾按键，或关闭占用程序后重新开始传译。

默认组合避开了微软公布的 [PowerPoint for Mac 放映快捷键](https://support.microsoft.com/en-US/accessibility/powerpoint/use-keyboard-shortcuts-to-deliver-powerpoint-presentations)。其他应用的自定义快捷键、PowerPoint 加载项及用户自行设置的组合无法全部自动识别；请在正式放映前试按一次。

## 开发验收

在 `VoxBridge/` 下运行 `../.venv/bin/python -m pytest tests/test_subtitle_shortcuts.py tests/test_native_localization.py -q`。测试覆盖热键占用与释放、长按与松手、显示器边界、法语键盘布局、隐藏后恢复当前字幕、无朗读模式分页，以及真实 PCM 输出在字幕连续操作期间正常播放完毕。音频检查只播放静音测试片段，不连接模型服务。

`tests/macos/SubtitleShortcutPresentationAcceptance.swift` 提供有时限的手工放映验收程序。使用它和一个临时 PowerPoint 文稿，可以检查 OS 实际发出的热键事件、前台应用、字幕可见性及移动距离；它不启动音频采集、不连接模型，也不保存用户偏好。

2026-09-15 本机验证：macOS 26.6.2、PowerPoint 16.112.4。全量测试 **1,241 项通过、32 项跳过**；有一条第三方 Starlette/AnyIO 弃用警告。App 构建及签名检查通过，原生设置界面的修改、保存、恢复默认、禁用与中英文切换通过。真实 Carbon 事件处理、按键注册／释放、字幕分页和静音 PCM 连续播放由自动化测试覆盖。

PowerPoint 临时两页文稿中，工具发送五组组合键均未翻页，普通右箭头正常前进。工具发送的按键没有触发系统全局热键回调，**真实键盘跨应用触发和长按体验尚未完成人工验收**，不能将前述兼容性检查视为这部分已通过。
