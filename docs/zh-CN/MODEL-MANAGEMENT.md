# 模型文件与下载管理

[English](../en/MODEL-MANAGEMENT.md) · [README](../../README.zh-CN.md)

本功能用于当前源码及本地更新版，现有 1.8.0 下载包尚未包含这个窗口。

在 App 主窗口或菜单栏选择 **模型管理**。首次安装窗口也可通过 **查看模型文件** 查看清单；首次安装未完成时，下载仍由原安装窗口负责。

## 文件与保存位置

窗口列出 Qwen3-ASR 0.6B、HY-MT1.5 1.8B Q8_0、Kokoro 多语言和中文语音模型、音色、分词及配置文件，以及 Silero VAD。当前清单包含 18 个模型及配套文件，全部保存后约 **4.88 GB**，包含本机生成的中文变速模型，不包含 Python 等运行环境。

每行显示模型名称、文件名、已保存字节、预计大小和文件状态。选择文件后可查看实际保存位置、固定版本的下载网址及 SHA-256，并可在 Finder 中定位文件或打开下载来源。

- 正式版通常保存在 `~/Library/Application Support/VoxHalo/assets/models/`。
- 源码安装使用当前服务项目上一级的 `models/`。窗口显示实际解析后的目录，不会把开发版模型迁移到另一位置。
- Qwen 权重文件保持原下载精度；运行时仍使用已验证的 MLX INT8 设置。中文 `kokoro-v1.1-zh-float-speed.onnx` 从已校验的原始模型本机生成，恢复结果必须匹配既有 SHA-256。

## 检查和恢复

| 状态／操作 | 含义 |
|---|---|
| 已保存，未校验 | 文件存在且大小符合；尚未进行本次完整校验 |
| 已校验 | 文件内容符合清单 SHA-256；文件更改后会失效 |
| 文件缺失 | 文件不存在，可补下载 |
| 部分下载，可继续 | 保留了 `.part` 文件，可续传 |
| 文件损坏，可修复 | 大小或校验值不符；修复前会保留具名备份 |
| 无法访问 | 权限、链接或文件类型异常；先处理对应原因 |
| 刷新状态 | 重新检查本机文件；窗口打开时也会自动刷新 |
| 校验完整性 | 在后台读取文件并核对 SHA-256，不下载文件 |

误删模型后，结束传译并点击 **停止服务**，打开模型管理，选择缺失的文件，再点击 **下载／修复所选文件**。也可以点击 **补齐／修复全部模型**，保留有效文件，仅恢复缺失或损坏的模型。无需删除其余模型或重新安装整个 App。

下载时显示当前文件、完成量、总量及百分比。**暂停下载**保留已完成文件和部分下载；再次点击下载按钮即可继续，服务器不支持续传时会重新下载该部分文件。关闭模型管理窗口不暂停下载；退出 App 会停止下载并保留进度。

查看文件可在服务运行期间进行。下载／修复仅在服务停止后可用，并与服务启动及正式版安装互斥。发生错误时打开 **下载详情**；网络恢复或释放足够磁盘空间后重试。只有下载需要联网，已安装模型的识别、翻译、朗读和字幕仍在本机运行。
