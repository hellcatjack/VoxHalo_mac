# 界面语言

**简体中文** | [English](../en/INTERFACE-LANGUAGES.md)

App 1.7.0（build 20）为主窗口、菜单、字幕设置、常见状态／错误提示、监控页、听众页和启用密码保护时的登录页提供八种界面语言：中文、英文、日语、法语、西班牙语、意大利语、葡萄牙语、印地语。

## 选择语言

在 App 顶部的 **界面语言 / Interface language** 菜单中选择语言。选择器始终用各语言自己的名称，便于切换回来。默认跟随 macOS 的首选语言顺序；例如 pt-BR 对应葡萄牙语，zh-Hant 对应本期提供的简体中文。若首选语言均不支持，则显示英文。

监控页、听众页和登录页各提供一个 **界面语言** 选择器，默认跟随浏览器的语言顺序。手动选择保存在当前浏览器的网站存储中，同一地址的页面共用该偏好；App 单独保存。选择“跟随系统”或网页“自动”可恢复自动选择；存储的语言不受支持时也会恢复自动选择。浏览器禁用本地存储时，当页仍可切换，但下次访问不保证保留。

界面语言可以在传译过程中切换。它不会修改识别／译音方向、设备、ASR 提示词、译文、已发布的朗读内容或播放状态。例如界面选日语，仍可以继续英文→法语传译。中文自动语速继续为 1.10–1.30 倍。

## 范围与资源

所有界面翻译均随程序离线提供，不调用 Qwen、HY-MT 或云端服务。实际原文、译文、字幕、设备名称和用户输入保持原样。系统自身界面（文件选择器等）按 macOS 语言显示；第三方错误的原始技术详情可能保留原语言。权限窗口使用系统选定的本地化说明，App 内的语言切换不会改变已打开的系统权限窗口。

资源位于 `VoxBridge/voxbridge/ui_locales/`。原生界面与浏览器各自读取资源，业务语言目录保持独立。旧的浏览器采集演示页不属于本机 App 默认产品流程，本期覆盖的是原生 App、被动监控、听众页及可选的登录页。

本次验证包括八语言资源及参数完整性、语言优先级与持久化、原生控件切换保留输入和设备、浏览器播放过程中切换语言保持音频与字幕，以及移动尺寸布局。通过编译和实际 App 的英文、日语、法语、印地语显示检查；不代表所有语言文案均经过母语用户校对，也不等于新增了语音识别／翻译质量保证。
