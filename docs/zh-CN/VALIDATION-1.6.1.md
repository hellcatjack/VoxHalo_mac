# 1.6.1 验证记录

[English](../en/VALIDATION-1.6.1.md) | **简体中文**

验证日期：2026-09-14。设备为 Apple M4、24 GB 统一内存、macOS 26.6.2。版本为 1.6.1（build 19）。行为说明见[朗读与字幕版本一致性](SPEECH-CONSISTENCY.md)。

## 测试方式

用 `NativeFileReplayChecks.swift` 按真实时间送入每方向 600 秒的单声道 16 kHz PCM，经过本机实际的 Qwen3-ASR 0.6B MLX INT8、HY-MT1.5-1.8B Q8_0、Kokoro、原生播放器及字幕时钟，使用系统默认音频输出。英文采用已下载叙事音频的第 4–14 分钟；中文采用已下载讲话的第 10–20 分钟。

这是服务与原生播放集成验证，文件输入替代了系统音频采集。因此本次长测不等同于重新验收 macOS 音频录制权限或浏览器声源隔离。没有更换模型或声音：中文使用 `zm_029`，英文使用 `am_michael`，自动语速保持开启。

| 服务或播放错误 | 0 | 0 |
| 朗读快照与 PCM 文本错配 | 0 | 0 |

两方向音频均按顺序播放并完成最终排空。中文→英语最后一次 100 ms 轮询采样还剩 2.67 ms；随后原生 `stop(drain: true)` 确认播放排空并回到空闲，不能把这一采样时间差误报为丢失尾音。

英语→中文有 8 句通过流式确认提前发布，其中 3 句使用低缓冲短窗口；83 句通过最终识别封存，5 句在结束时完成排空。观察到 1 次确认撤回。中文→英语有 32 句流式提前发布，47 句最终识别封存，1 句结束排空。

所有已发布朗读记录保持不可变。中文→英语实际发生 1 次播后修订：原朗读记录保留，新的完整译文单独作为校订记录；没有替换播放字幕或追加重播该句。

## 回归与界面

- 完整 Python 测试：**1013 通过、6 跳过**，171.19 秒。跳过项为可选 ONNX 模型转换检查 1 项、Playwright 浏览器检查 3 项、需要额外 `ffprobe` 的检查 2 项；另有 1 条 Starlette 依赖弃用警告。
- 新增确定性回归覆盖待播修订替换、原始 ASR 撤回、否定/数字确认、编码器阻塞、撤回后重新计时、同版本重试、最终尾句排空与兼容监听通知。
- Swift 播放字幕检查通过：排队、暂停和缺音时保持字幕，在对应音频开始后切换。
- 实际浏览器核验监控页正常加载，朗读后的校订默认折叠，展开不会替换已发布朗读记录；未发现浏览器脚本错误。
- 原生 App 编译和严格签名验证通过。

## 解释范围

本轮检查音频顺序、版本一致性、字幕进入时间、连续衔接及最终排空，没有进行人工逐句翻译质量评分。完整语义正确性仍取决于 ASR 和翻译模型；后续语境也可能改变译法。

既有普通 3 秒、低缓冲合格句 1 秒的参数未上调。提前翻译和预合成继续与确认等待重叠。英语的风险提示可能让个别句子比以前更晚发布；这次集成验证并非隔离负载的延迟 A/B 基准，不能据此声称整体延迟下降。

原始音频、逐句文本、运行日志和诊断 JSON 仅保存在本地，未上传仓库。
