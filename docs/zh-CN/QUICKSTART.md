# 在 Mac 上安装同声传译

[English](../en/QUICKSTART.md) | **简体中文** · [README](../../README.zh-CN.md)

**1.8.0 桌面发行版**内置 App、Python 和主要 AI 运行环境。使用者无需终端命令、Xcode、Homebrew、Docker、单独安装 Python，也不需要云端 API 密钥。

## 下载前确认

- **Mac：**Apple Silicon，M1 或更新芯片；不支持 Intel 或 Rosetta。
- **macOS：**14.2 或更新版本。发布包中的原生依赖面向这一兼容下限；完整同传系统已在 MacBook Air M4 / 24 GB / macOS 26 上验证，较早机型和系统仍需分别验证实时性能。
- **内存：**桌面安装器要求至少 16 GB，日常使用优先选择 24 GB 或更多。8 GB 的实时表现尚未验证。
- **空间：**安装期间至少预留 20 GB。
- **网络：**首次需要下载 App，以及约 4.61 GB 的模型和语音组件，安装还会生成约 344 MB 的中文语速模型。安装完成后，识别、翻译、朗读与字幕可以离线运行。
- **模型许可：**HY-MT 翻译模型遵循独立的 Tencent HY Community License，其许可地域不含欧盟、英国和韩国。安装窗口提供完整许可，并要求使用者确认自己的使用符合条款。App 公开下载不等于额外授予模型许可。

## 1. 下载桌面版

打开 [GitHub Releases](https://github.com/hellcatjack/VoxHalo_mac/releases/latest)，在 **Assets** 中下载 **VoxHalo-1.8.0-macOS-arm64.dmg**。

建议选择 DMG。ZIP 是同一 App 的另一种压缩格式；GitHub 自动生成的 **Source code** 是开发者使用的源码，不是可以直接打开的安装包。

## 2. 放入“应用程序”

双击 DMG，把 **同声传译.app** 拖到 **Applications（应用程序）** 快捷方式。推出磁盘映像，再从“应用程序”打开同声传译。名称会跟随系统语言显示，英文系统中显示为 **Simultaneous Interpretation**。

如果当前账户不能写入系统“应用程序”目录，也可以把 App 放入用户主目录内的“应用程序”文件夹。之后保持 App 的位置稳定，便于 macOS 记住音频权限。

### 首次打开的 macOS 提示

本版使用 **ad-hoc 签名，尚未通过 Apple Developer ID 公证**。macOS 首次打开时可能提示无法验证开发者。在确认文件来自本项目的 Release 页面后，可以按 Apple 的说明，在 **系统设置 → 隐私与安全性 → 仍要打开** 中为这一个 App 放行（如果系统提供该选项）。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

不要关闭 Gatekeeper 或整台 Mac 的安全保护。受组织管理的电脑可能需要管理员许可。校验和只能确认下载内容没有变化，不能替代 Apple 公证。

## 3. 在 App 中安装模型

首次启动会显示本地模型安装窗口。选择界面语言，阅读模型许可，并确认 HY-MT 条款允许自己的使用，再点击安装按钮。

App 会依次：

1. 把随包提供的运行环境解压到当前用户目录。
2. 下载固定版本的 Qwen3-ASR、HY-MT、Kokoro、VAD 模型、日语词典、llama.cpp，以及两个已经编译好的语音组件。
3. 检查每个下载文件的 SHA-256，准备中文语速控制模型，并检查运行环境。
4. 在安装完成后启用主控制台；安装过程不会自动开始录音。

可以取消安装，之后再重试。已经完成并通过校验的文件会复用，中断的下载会在服务器支持时断点续传。首次安装期间请保持 Mac 唤醒。出现网络或空间错误时，处理提示的原因后重试，不必先删除整个模型目录。

## 4. 选择声音和语言

在主控制台中：

1. 选择**输入来源**：系统声音、只听译音的系统声音，或麦克风。
2. 选择**朗读输出**：系统默认、耳机，或其他可用设备。
3. 选择识别语言和翻译朗读语言。中文、英文、日语、法语、西班牙语、意大利语、葡萄牙语、印地语均可作为输入或输出。
4. 点击**开始传译**；macOS 请求相应音频权限时按需允许。首次启动服务要加载模型，可能比后续启动稍慢。
5. 采集启动后，再讲话或播放音频。

如果希望用耳机只听视频译音，选择**系统声音·只听译音**，再选择耳机或系统默认输出。App 会在采集期间抑制原声并播放译音；请暂停无关应用的声音。

麦克风模式需要麦克风权限。系统声音采集需要当前 macOS 显示的屏幕／系统音频录制权限。按所选来源授权即可；如果采集被拒绝，可到**系统设置 → 隐私与安全性**检查，并在系统要求时重启 App。

## 5. 字幕、监控与停止

桌面字幕跟随本机实际朗读，外观和位置可在字幕设置中调整。网页监控页用于查看文本和状态，关闭网页不会中断业务。

手机和平板可以在同一局域网扫描 App 的二维码收听。局域网收听不需要互联网，但设备之间必须可以互相连接；所有听众收听当前场次所选的同一种目标语言。

结束时先暂停声源。**结束传译**停止采集，**停止服务**释放模型。关闭主窗口后仍可从菜单栏返回；选择**停止服务并退出**才会完整退出。

## 文件位置、更新和卸载

发行版把不同版本的运行环境和共享模型保存在 **~/Library/Application Support/VoxHalo/**。在 Finder 选择**前往 → 前往文件夹…**，粘贴该路径即可查看。服务或安装正在运行时不要重命名内部文件。

- **更新：**停止服务并退出，再用新发行版替换 App。模型独立保存，校验一致时可复用；各版本拥有独立运行环境。
- **已有源码安装：**建议先保留，确认下载版可用后再自行整理。桌面发行版使用自己的运行目录，不依赖、移动或删除旧项目；界面语言和音频偏好仍保存在 macOS 偏好设置中。
- **重试：**重新打开安装窗口即可。已校验完成的文件会保留；发现已有文件损坏时会报告并保留。点击明确的修复操作后，安装器会保留具名备份并下载通过校验的替代文件。
- **卸载：**退出后把 App 移到废纸篓。如需同时删除模型和运行环境，再删除 VoxHalo 的“应用程序支持”目录。只删除 App 会保留模型，以便以后重装。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 下载停住或失败 | 确认网络可以访问 GitHub、Hugging Face 和 files.pythonhosted.org，再从 App 重试 |
| 空间不足 | 清理用户目录所在磁盘，预留 20 GB 后重试 |
| 校验和不一致 | 保留错误详情并重试；持续失败请反馈，不要使用未完成文件 |
| 无法开始传译 | 先完成模型安装，再等待服务状态检查结束 |
| 识别不到声音 | 检查输入来源、识别语言、macOS 权限，以及声源是否正在播放 |
| 听不到译音 | 检查输出设备和音量，确认设备仍连接 |
| 手机无法连接 | 使用 App 显示的局域网地址，确保设备在可互通的网络；回环地址只适用于 Mac 本机 |

反馈时请在 [GitHub Issue](https://github.com/hellcatjack/VoxHalo_mac/issues) 提供 App 版本、Mac 芯片／内存／系统、翻译方向、输入输出选项及错误文字。分享日志前去掉私人字幕和本地控制凭据。

开发者仍可使用[源码安装指南](INSTALLATION.md)。模型、音色和许可证详情见[模型指南](MODELS.md)。
