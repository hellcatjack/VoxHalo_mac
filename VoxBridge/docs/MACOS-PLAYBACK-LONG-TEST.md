# 原生朗读长测与载流静音优化

2026-09-13，MacBook Air M4 / 24 GB，服务端口 8024。播放测试对应 build 6 的算法；最终交付为 App 1.1.0 build 7，追加了麦克风权限等待的取消修复，播放算法未再更改。

使用指定视频 [《持守复兴的生命》](https://www.youtube.com/watch?v=q5tBWsDc8gI) 的 00:00–10:00 音频。先做旧播放器前 3 分钟对照，再用优化播放器按原速运行完整 10 分钟。通过原生采集接口注入该视频的 PCM，实际运行 Qwen3-ASR → HY-MT → Kokoro → 原生 AVPlayer；朗读输出到本机默认设备。它验证完整业务与播放器，但不替代 ScreenCaptureKit 或麦克风录音设备验收。

Qwen3-ASR 0.6B MLX INT8、HY-MT 1.5 1.8B Q8_0 的既有提示词与采样、Kokoro 音色/线程/基准速度均保持不变。ASR 术语为原设置“尼希米、同工”。

3 分钟旧版对照发现 6 处已经满足可跳转条件却继续播放载流静音，采样累计约 13.759 秒；优化版 10 分钟中相同条件下的采样等待约 1.596 秒。两次运行长度不同、模型缓存和分句时机也会变化，这些数值用于定位机制，不能直接换算为整体延迟改善百分比。25 次实际跳转及其落点、耗时是本次优化最直接的证据。

进程 RSS 采样峰值：识别/TTS 服务约 1304 MiB，HY-MT 约 2199 MiB，原生测试播放器约 59 MiB。RSS 不等于整个系统或 Metal 的全部内存使用。温度状态只出现 nominal/fair，没有 serious/critical；采样时系统内存压力正常。监控页曾在运行中打开并关闭，业务继续。

## 播放行为

原生 App 保留 `continuous=true` 的连续 HLS 媒体序号，避免旧版通过跳跃裁剪服务端播放列表导致的 AVPlayer 卡住。每 500 ms 获取语句时间标记，每 100 ms 判断：

1. 上一句语音已经结束。
2. 服务端明确标记存在可丢弃的载流静音，且所有语句时间递增、不重叠，静音长度与恢复时间一致。
3. 下一句开头以及 100 ms 音频已经进入 AVPlayer 可跳转窗口。
4. 跳转保留尚未经过的自然停顿，并至少留下 250 ms 句首解码余量；小于 500 ms 的可节省时间继续正常播放，避免频繁小跳转。

同一句只尝试一次；快照读取失败时继续普通播放。正常结束期间仍可压缩最后一句之前的载流静音。取消或重新开始后，旧请求/旧跳转回调不能恢复已经停止的播放器。

## 尚存的等待与验证边界

这不是全程无停顿的承诺。本次全部句间隔中最长约 **14.662 秒**：下一句尚未产生，以及生成后的音频尚未进入 HLS/AVPlayer 可播放窗口时仍须等待。例如一次长停顿中，字幕发布后约 3 秒才满足原生可跳转条件，随后才跳过剩余载流静音。继续降低这类延迟需要分别优化生成时机和音频传输缓冲，不能用跨过尚未读出的语音来掩盖等待。

时间统计依据 AVPlayer 播放位置和服务端语音活动标记，采样约 100 ms；没有声卡输出回录或逐字人工听辨，因此“未跨语音标记”不等同于主观音质或每个音素已经验收。测试中经文专名仍可出现识别错误，本次没有修改识别模型或翻译设置来掩盖这类问题。

## 回归与复现

- `HLSPlaybackGapChecks.swift`：正在说话、不足缓冲、分离窗口、自然停顿、异常时间、重叠语句与静音元数据不一致；新增反例先失败后通过。
- `NativeLifecycleChecks.swift`：冷启动取消、设备消失、等待采集时取消、并发停止全部通过。
- Python 服务管理、监控、HLS 与听众页回归：100 passed，6 skipped，1 个既有 Starlette/AnyIO 弃用警告。
- 10 分钟测试开始后补充的异常快照拒绝逻辑不改变有效快照的播放算法；最终构建另做 60 秒实机回归。
- 最终 60 秒源音频复测总计 82.79 秒，输出 11 句并正常释放资源。归档的 83 个完整 HLS 片段可连续解码为约 83.03 秒音频，峰值 0.619、RMS 0.050，确认实际输出语音。
- build 7 的权限等待测试覆盖允许、拒绝、停止、任务取消、晚到回复和再次请求；PCM 转换、麦克风恢复及原生生命周期复测通过。

最后的 App 界面检查暴露 macOS 重新授权时的取消问题：旧的 async 权限请求会一直等用户回复，连带阻塞停止。build 7 改为可取消的回调等待，旧授权回复不能恢复旧会话。最终 App 已安装并打开，但系统当前仍在询问访问桌面项目的权限；麦克风录音也需要用户允许。没有绕过系统授权，也未宣称本次新构建的真实录音权限验收完成。所有测试音频及原生监听已停止，模型服务保持就绪。

原始结果位于 `artifacts/macos/q5tBWsDc8gI/`：`baseline/`、`optimized/`、`final-smoke/`、`regression.log`、`lifecycle.log`。长测的 HLS 文件只是诊断采样，并非完整输出录音；最终复测工具仅归档播放列表已发布的完整片段。
