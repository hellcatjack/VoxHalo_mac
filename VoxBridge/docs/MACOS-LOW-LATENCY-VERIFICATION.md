# 低延迟原生朗读开发验证

> 名称说明：当前项目中文名称为“同声传译”。本文保留验证当时使用的应用名称与路径。

适用版本：教会同声传译 1.2.0（build 8）。本机为 Apple M4、24GB 内存；工程位于 `<workspace>/VoxBridge`，服务端口仍为 8024。

## 已实现

- 完整译文仍经正式提交与修订保护，再按自然语句边界合成短块。首块完成后可先发布；后续块与发布并行推进。只有最后一块添加原有300ms句末停顿。
- 本机使用 AVAudioEngine/AVAudioPlayerNode 播放 PCM，按采样位置衔接已有缓冲，不经过 HLS 播放窗口或载流静音。局域网继续使用共享 HLS；两种输出共享一次合成。
- 实际待播≤2秒时，已确认原文的稳定阈值从3秒降至1秒。反馈每250ms更新、2秒过期；失效后恢复3秒。未确认最新句仍须封口，最终重识别与修订校验保留。
- 可选预翻译只接受至少两次真实解码一致、持续至少0.6秒且已有自然边界的候选。精确匹配原文、方向、会话、版本、全部提示词与推理设置才能复用；不提前发布字幕或音频。正式任务优先，预计算最多一项。默认关闭。
- PCM与预合成缓存分别限制为16MiB原始音频/256块。先到的正式句子能回收后续未消费缓存，避免队首被缓存容量阻塞。发布与PCM游标提交保持一致；缺块、错误顺序、旧会话回调和截断句尾不会被当作完整播放。

Qwen3-ASR 0.6B MLX INT8、HY-MT1.5-1.8B Q8_0、教会提示词、mac-verified采样参数、Kokoro音色/CPU2线程及基础速度1.05均保持不变。

## 测量方式

输入为指定视频 `q5tBWsDc8gI` 的本地前600秒PCM，SHA256：`7be90f42f12ce580a24189727966e12ef9bb5a1f01a0a67633e13659afbfb935`。按100ms块以原速注入真实 NativeSession，经过本机ASR、HY-MT、Kokoro及真实音频输出引擎；浏览器不参与业务。没有重新下载视频或延长源音频。

原生渲染进度约100ms采样，monitor返回时记录独立观察时间（约500ms间隔）。仅测试编译通过播放器回调归档收到的PCM，不额外创建或续期监听连接。使用与旧HLS字幕相同的10ms能量检测器定位语音首尾，因而句间间隔包含自然停顿和原有300ms句末停顿。

渲染记录不等于物理扬声器回录；原文提交时间不等于讲者说完的时间。测试是文件注入，不能替代系统声音/麦克风权限和回流排除的实机验收。此次Mac锁屏，未操作新版App窗口。

新版下一句PCM已就绪的53个句间隔，中位数0.522秒、最大0.769秒，包含自然停顿与300ms句末停顿。分块已排队时按同一采样边界衔接，没有附加HLS载流等待。本机待播峰值11.117秒。

全部长停顿的次数没有下降：较快追上原音后，会更多暴露讲者停顿、原文确认和翻译生成的等待。原文已译好却仍等待的长间隔则显著减少。两次ASR切句和文字并不完全相同（87/88句）；24条完全一致且唯一的原文配对中，提交至开口中位数为9.934→2.703秒，逐条延迟变化的中位数为−6.271秒。以上是整条新版链路的观察对比，不能分解为每个改动各自的因果收益，也不是识别准确率评估。

40句使用低缓冲的1秒阈值，实际原文稳定年龄中位数1.168秒；23句在封口后放行，25句沿用普通3秒窗口。识别与翻译进程合计RSS峰值3398MiB（约3.32GiB，不代表全部统一内存/GPU占用）。系统热状态为正常或轻度，未记录严重/临界状态。

## 预翻译默认保持关闭

另以同视频前120秒作显式启用对比：20句、35块全部播放并正常结束。5次预计算全部完成，4次被正式请求复用、16次正式请求走普通计算。10条完全一致且在110秒前提交的原文，其译文也全部相同；提交至译文的中位时间为关闭0.790秒、开启0.800秒。逐条开口延迟差的中位数只改善0.044秒，处于约100ms渲染采样及500ms文本采样误差内。

因此保留代码和显式开关，默认关闭；这次短样本不能证明默认开启有稳定收益。两次ASR边界和热状态并非完全相同，不能把小幅差异当成确定的加速或减速。

实测还发现旧诊断计数把被正式请求持有、随后失效的预计算同时计为“命中”和“作废”。实际字幕和音频未受影响；此处5次完成/4次复用以对应事件及单正式worker为依据，旧wasted计数不用于收益结论。该计数边界已修复并通过独立复审及40项专项检查，涵盖等待结果时取消、完成时取消及多个正式请求共享结果；推理调度没有改变。正式交付使用修复版，旧A/B文件保留原始计数以便追溯。

## 故障恢复及交付

受控终止本安装所属后端后，新版原生会话约0.123秒发现断连并停止。恢复8024后，同一控制器重新连接、启动原生PCM监听并正常结束。测试明确使用默认输出设备。没有终止其他安装或应用的模型进程。

最终保留分块TTS、原生PCM和低缓冲稳定门；预翻译默认关闭。所有测试音频均已停止，模型服务保持就绪。新版App已安装并重开；Mac锁屏，因此本轮没有点击窗口或重新验收麦克风/系统声音授权。
